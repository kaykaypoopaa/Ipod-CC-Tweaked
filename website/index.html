UILib:

UILib.setup(), this function is essential to the uilib working, if you don't run this function, it simply will not work.
Syntax:
UILib.setup(monitor)
1. Monitor: Peripheral; monitor / term
Example usage:
 local monitor = peripheral.find("monitor")
UILib.setup(monitor)

UILib.addButton(), this function creates a button on the screen.
Syntax:
UILib.addButton(x, y, width, height, label, color, action)
1. x: number; x position of the button
2. y: number; y position of the button
3. width: number; width of the button
4. height: number; height of the button
5. label: string; the text to display on the button
6. color: color; the color of the button
7. action: function; the function to run when the button is pressed
Example usage:
 UILib.addButton(10, 10, 100, 20, "Click Me", colors.blue, function() print("Button Clicked!") end)
